# fullstack_developer_capstone - Dealerships Web Application

## Project Overview
The Dealerships Web Application is a full-stack web application designed for browsing car dealerships, submitting dealership reviews, and analyzing customer feedback. Built with a Django back-end, React front-end, Node.js microservices, and IBM Watson Sentiment Analysis API, the application allows users to register, log in, view dealerships across various states, and manage vehicle reviews seamlessly.

## Repository Details
- **Repository Name:** `fullstack_developer_capstone`
- **Project Name:** Dealerships Web Application

## Features
- **General Users:** Browse dealerships nationwide, filter dealerships by state, view detailed dealership reviews, and access About Us / Contact Us pages.
- **Registered Users:** Register a new account, log in/logout securely, post new dealership reviews, and view sentiment analysis on reviews.
- **Admin Panel:** Manage car makes, models, and dealership records via Django Administration.
- **Microservices & Sentiment Analysis:** Node.js Express server to fetch dealerships/reviews from a database and sentiment analysis microservice for automated review evaluation.

## Tech Stack
- **Front-End:** React.js, HTML5, CSS3, Bootstrap
- **Back-End:** Python, Django
- **Microservices:** Node.js, Express.js
- **Database:** SQLite / MongoDB
- **Cloud & CI/CD:** IBM Cloud Code Engine, GitHub Actions
